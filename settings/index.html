Jeux

Chemins utilisés par les boutons « Lancer ». La télémétrie est détectée automatiquement (AC Evo, AC 2014, AMS2) ; ces chemins servent uniquement à démarrer le jeu.

Carte ETS2 / ProMods
…

Carte vectorielle extraite des fichiers ProMods, avec zoom et déplacement. Les tuiles ts-map restent le fallback si aucune carte vectorielle n’est installée.

Carte ProMods fidèle (ts-map)
…

Génère les tuiles complètes depuis base.scs + ProMods. Le mode 0-7 est recommandé pour le 7" (rapide, net). Le 0-8 est plus long et peut prendre plusieurs Go.

Ambient lights (DX Light / Robobloq)
…

Ferme DX Light avant : un seul programme peut contrôler le bandeau. Clignotants gauche/droite, régime, drapeaux, frein, ou sync écran comme DX Light.
