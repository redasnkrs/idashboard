Ouvrir les releases GitHub ↗

Télécharge le ZIP de la dernière release depuis GitHub, puis sélectionne-le ici. idash-vX.Y.Z-win64.zip installe la version .exe ; idash-vX.Y.Z.zip reste disponible pour les anciennes versions. L'application garde tes données (custom/, thèmes, app.json, profil Chrome) et redémarre automatiquement.

Pour créer une release : incrémente VERSION, commit, puis pousse un tag vX.Y.Z. Le workflow GitHub Actions construit le ZIP et crée la release.
